# The Mythology of Music

Built on the supplied Stagehand-Windows-RehearsalRoom update. Guitar Hero-inspired rough ink, screenprint colors, musical mythology and compact menu stickers. The selected artwork is in src/renderer/art/mythology; full-size masters and exact generation prompts are here. Artwork/Drafts-and-masters in the combined ZIP includes all completed generated images, including unused explorations.

Menu banners, sidebar stickers, settings, guide and empty states use separate shuffle pools. Returning to a menu selects another image; ordinary redraws keep the current selection. Pins and the rotation preference are respected. Main menu images are reduced from 300x226 to 180x144; compact spot illustrations are 104x104. The wide Creation reference uses a 240x112 area and is hidden on narrow layouts.

Highway, audio engine, latest gear controls and gear images are preserved from the supplied update. Gear image corrections are deferred. Existing automated tests passed; the menu rotation and gear control checks are included. Full Windows layout/audio acceptance testing remains pending.

This is a working visual update, not complete artwork coverage of every catalog item. The Windows folder uses the existing script installer, which downloads runtime dependencies; no new standalone installer EXE was built.
